# Hyperskill_Coffee_Machine-Java

## Overview
Hyperskill_Coffee_Machine-Java is a console-based application that simulates the functionalities of a coffee machine. Developed in Java, this interactive Command Line Interface (CLI) application allows users to manage resources and select from various coffee types. It's an excellent project for understanding the basics of Java programming and command-line operations.

## Features
- **Interactive CLI**: Choose from a variety of coffee options through an intuitive command-line interface.
- **Resource Management**: Keep track of available resources like water, milk, and coffee beans.
- **Dynamic Operations**: Add or remove resources as needed to simulate real-world coffee machine operations.
- **Simple Logic Implementation**: Experience an application structured with fundamental programming logic.

## Setup & Installation
To get started with Hyperskill_Coffee_Machine-Java, follow these steps:

1. **Clone the Repository**
   ```bash
   git clone https://github.com/username/Hyperskill_Coffee_Machine-Java.git
   ```
2. **Navigate to the Project Directory**
   ```bash
   cd Hyperskill_Coffee_Machine-Java
   ```
3. **Compile the Java Program**
   ```bash
   javac CoffeeMachine.java
   ```
4. **Run the Application**
   ```bash
   java CoffeeMachine
   ```

## Usage
Once the application is running, follow the on-screen prompts to interact with the coffee machine. You can choose different coffee options and manage resources as needed.

Example:
```plaintext
> Choose a coffee type:
1 - Espresso
2 - Latte
3 - Cappuccino
> Enter your choice: 1
```
