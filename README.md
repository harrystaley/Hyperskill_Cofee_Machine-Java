# Hyperskill_Coffee_Machine-Java

![Java](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=java&logoColor=white)

## Overview

Hyperskill_Coffee_Machine-Java is a console-based Java application that simulates the operations of a coffee machine. The project focuses on resource management and dynamic command-line interactions, making it an ideal learning tool for beginners in Java programming.

## Features

- **Simulated Coffee Machine Operations**: Choose from a variety of coffee options, each consuming different amounts of resources.
- **Resource Management**: Track and manage the machine's resources such as water, milk, and coffee beans.
- **Dynamic Command-Line Interface**: Interact with the coffee machine through a user-friendly CLI.
- **Educational Focus**: Designed to help Java beginners understand basic programming concepts and logic.

## Setup and Installation

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/yourusername/Hyperskill_Coffee_Machine-Java.git
   ```
2. **Navigate to the Project Directory**:
   ```bash
   cd Hyperskill_Coffee_Machine-Java
   ```
3. **Compile the Java Program**:
   ```bash
   javac CoffeeMachine.java
   ```
4. **Run the Application**:
   ```bash
   java CoffeeMachine
   ```

## Usage

Once the application is running, you can interact with the coffee machine by following the prompts. Here are some example commands:

- **Buy Coffee**: Select a coffee type to purchase (e.g., espresso, latte, cappuccino).
- **Fill Resources**: Add resources to the machine when prompted.
- **Take Money**: Collect the money from the machine.
- **Check Status**: View the current resources status.
